# Vahe Petrosyan — Portfolio

Personal portfolio site. Zero build step — plain HTML, CSS, and a little vanilla JS.

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```

## Structure

```
index.html     markup and content
styles.css     theme (light/dark), layout, animations
script.js      theme toggle, scroll reveal, nav state
assets/        downloadable CV
```

## Deploy (GitHub Pages)

Push to a GitHub repo and enable Pages on the `main` branch (root). The site is fully static.
